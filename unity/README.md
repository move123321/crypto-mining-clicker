# Crypto Mining Clicker — Unity

Fresh Universal 2D 5.1.0 template project.

- Editor: Unity 6000.0.73f1 LTS
- Renderer: Universal Render Pipeline, 2D Renderer
- Starting scene: Assets/Scenes/SampleScene.unity
- Previous game scripts have been removed; this is a clean starting point.

Open this folder using Unity Hub with the editor version above. Allow package import and automatic API updates to finish.

Unity Version Control (com.unity.collab-proxy) is pinned to 2.12.4, the installed editor's supported version, to avoid ObjectInfo compilation errors from the template's older 2.6.0 package.
