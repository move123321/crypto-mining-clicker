# 출시 전 점검 — 2026-10-05 / 1.3.2

## 수정한 문제

- 상위 GPU를 고장으로 잃으면 코인 거래·채굴 선택이 다시 잠기고, 해당 코인 계약도 진행하기 어려웠습니다. 이번 회차의 코인 해금 기록을 저장하도록 수정했습니다. 환생하면 다시 초기화합니다.
- 이전 저장 파일은 보유 장비, 코인 잔액, 진행 중인 계약을 통해 해금 기록을 복구합니다.
- 음수 보상이나 존재하지 않는 코인을 가리키는 계약, 중복 쿨러 ID가 저장 검사에서 누락됐습니다. 해당 파일을 정상으로 취급하지 않고 기존 백업 복구 경로를 사용합니다.
- Unity가 예전 파일에 기록한 빈 계약 객체는 계약 없음으로 정상 변환합니다.

## 확인 결과

- 수정 전: 새 회귀 검사 6개 실패로 문제 재현.
- 수정 후: 기존 123개 검사와 새 15개 검사 통과.
- 냉각 장착 상태로 14,400초의 게임 진행을 가속 실행. 코인 판매, 계약 보상 수령, 10분마다 저장 데이터 재로드 후 진행 지속 확인.
- 시세 기록이 코인별 최대 60개로 유지되는지 확인.
- 720×1280, 1080×2400에서 설정·목표·장착·보관함·냉각·상점·포크·거래소·부동산 총 18개 화면 조합 렌더링 및 뒤로가기 확인. 활성 텍스트 넘침 0개.
- 거래소·목표·상점의 작은 화면 렌더링을 직접 검토.

검사 진입점: `ReleaseAuditChecks.Run`, `ReleaseLayoutAudit.Run`.

## 아직 검증되지 않은 사항

- 연결된 Android 기기가 없어 실제 Galaxy 설치·터치·키보드·앱 전환·발열·배터리 테스트는 수행하지 못했습니다.
- 4시간 검사는 게임 로직의 가속 시뮬레이션입니다. 4시간 실제 실행 성능이나 메모리 안정성을 입증하지 않습니다.
- 초보 플레이어의 이해도, 성장 속도의 재미, 장시간 반복 플레이 만족도는 플레이테스트가 필요합니다.
- 모든 UI 상태와 문구 조합을 검증한 것은 아닙니다. 아주 큰 잔액, 다른 화면 비율, 접근성 설정도 추가 확인 대상입니다.
- 개발자명·문의 이메일은 미정이며, 출시용 서명과 스토어 등록 준비는 남아 있습니다.

현재 판정: 내부 테스트 배포 가능. 정식 출시 준비 완료로 판정하지 않음.

## 재검사 및 적용 결과 — 1.3.3

- 팬 회전 프레임마다 최고 온도를 한 번만 계산하고, 최고 온도 조회가 장착 목록을 새로 만들지 않도록 수정했습니다. 전체 메뉴 또는 컷신이 열린 동안 방 팬은 회전하지 않습니다.
- 냉각 연구소 버튼은 열린 동안 해금 시간·현금·장착 상태에 맞춰 문구와 사용 가능 여부를 갱신합니다. 구매 순간에도 조건을 재검사합니다.
- 장식 UI 이미지는 Raycast Target을 끄고, 버튼·스크롤 뷰포트·입력칸·전체 화면 팝업에서만 입력을 받도록 정리했습니다.
- 거래 차트는 매 0.2초마다 강제로 다시 그리지 않고 시장 변경 이벤트 때 갱신합니다.
- 자동 검사: 기존 123개 + 새 출시 점검 15개 통과. 두 화면 크기 × 주요 메뉴 18개 조합에서 활성 텍스트 넘침 0개. 컷신 건너뛰기·뒤로가기 회귀 검사 통과.
- 이번 변경으로 절감된 실제 CPU/GC 시간은 프로파일러에서 측정하지 않았습니다.
- 저장 동기 작업, 런타임 음악 생성, 큰 메뉴 텍스처 변경은 이번에 수정하지 않았습니다. 손상 복구, 음질, 화면 선명도를 유지한 채 적용하려면 실제 기기 측정이 필요합니다.
- Android 기기가 연결되지 않아 Galaxy 실기기 확인은 미실행입니다.

- 이번 검사는 가속 게임 로직과 에디터 UI 렌더링입니다. Galaxy 성능·터치·발열 측정은 포함하지 않습니다.
