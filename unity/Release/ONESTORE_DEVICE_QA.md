# Galaxy 1.3.6 설치·조작·재실행 검사

정리일: 2026-10-11 (한국 시간)
대상: Galaxy A90 5G SM-A908N / 정식 서명 1.3.6, versionCode 10
범위: 출시 APK의 짧은 실제 기기 기능 검사. 30분 성능 검사나 모든 게임 동작의 보증이 아님.

## 확인 결과
- 정식 서명 APK 설치 및 실행 성공. 기존 별도 성능측정 앱은 삭제하지 않음.
- 인트로·튜토리얼 건너뛰기 버튼을 실제 입력으로 확인.
- GPU 터치 및 자동 채굴 후 진행 수치 증가 확인.
- 음악·효과음 슬라이더에 드래그 입력: 화면에 각각 39%, 27% 표시.
- 음소거 후에도 음악 39% 값 유지, 음소거 해제 버튼 동작 확인.
- 60FPS 선택과 팬 회전 끄기 상태 표시 확인. 실제 60FPS 달성률 측정은 하지 않음.
- 홈 화면 전환 → 앱 강제 종료 → 재실행 후 음악 39%, 효과음 27%, 60FPS 선택, 팬 회전 꺼짐 유지.
- 재실행 후 GPU와 누적 진행 유지. 종료 전 화면 124 코인, 이후 추가 플레이 화면 192 코인 확인. 두 캡처 사이 플레이 시간이 포함되므로 같은 시각 잔액 비교나 오프라인 수익 정확도 검증은 아님.
- 검사 후 30FPS, 팬 회전 켜짐으로 복원. 음악·효과음은 원래 최대값으로 되돌리는 드래그 입력 수행.
- 설정 화면 스크롤, 개인정보 안내 진입, X 닫기 및 Android 뒤로 가기 확인.
- 장비 상점·냉각·코인 거래소 화면 진입 및 실제 스크린샷 촬영.

- 잠금 후 사용자 재인증을 포함한 복귀, 전화 수신, 저사양 타 기기, 이번 버전의 장시간 발열·배터리.
- 이전 테스트 서명 앱에서 정식 서명 앱으로 데이터 이전 및 구버전 업데이트. 서명 변경으로 직접 업데이트는 불가.
- 구글 클라우드 저장(미구현), 원스토어 결제(미구현), 원스토어 심사 통과.

새로운 확정 오류는 이번 범위에서 관찰되지 않아 게임 코드는 추가 수정하지 않음.
