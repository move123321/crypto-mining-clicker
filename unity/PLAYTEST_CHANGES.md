# 플레이 테스트 개선 · 1.1.0

- 기본 GPU 1개, 추가 냉각·오버클럭·클릭 없음: 30°C에서 접속 중 600초 후 70°C.
- 백그라운드, 앱 포커스 해제, 튜토리얼, 과열 선택 중에는 채굴 및 발열 정지. 오프라인 시간을 가산하지 않음.
- GPU 9종의 색상·섀시·팬 구성을 구분하고 랙/상점/장착 관리/보관함에 공통 표시.
- 장착 관리는 슬롯과 업그레이드, 보관함은 미장착 GPU와 보유 쿨러 담당.
- 쿨러 하나를 랙에 장착: 1단계 1행(2개), 2단계 2행, 3단계 3행, 4~5단계 4행. 위쪽 행부터 적용. 기존 구매 쿨러는 보존하고 기존 장착분 중 최고 등급을 랙에 이관.
- 100°C에서 채굴 중지 후 수리 선택. 수리비는 장착 장비 원가 합계의 8%, 최소 500원. 수리 시 전체 30°C. 포기 시 장착 GPU 무작위 1개만 삭제하고 다른 진행을 보존.
- 마지막 GPU를 잃은 경우 보관함에서 기본 GPU 재시작 지원 가능. 코인을 팔아 수리비를 마련하는 버튼 포함.
- 코인 일반 변동 폭을 이전의 18%로 조정. 뉴스 시세 충격도 축소. 전기요금 ±20~30%, GPU 구매 가격 ±15%의 3분 이벤트 추가. 시간은 접속 중에만 경과하고 저장됨.
- 전기요금: 총 전력 / 15원(분당), 기본 GPU는 분당 12원. 상점 가격은 이벤트 종료 시 열린 화면에서도 갱신.
- 신문 형태의 작은 뉴스 창, 쿨러 그림, 포크 업그레이드 카드와 아이콘 추가. 환생 버튼은 조건 상세 확인 후 실행.
- 배경음악과 켜기/끄기 버튼, 상태 및 메뉴 한국어화, 왼쪽 위 실제 시계 제거. 모델명과 코인명은 유지.
- 메뉴 두 개를 서로 다른 역할로 유지하므로, 메뉴 삭제를 전제로 한 부동산/가로 맵 확장은 적용하지 않음.

## 검증

Unity 6000.0.73f1에서 `-batchmode -quit -projectPath <project> -executeMethod GameplayChecks.Run -logFile <log>`로 재검사 가능.
실제 사용자 세이브를 저장하지 않고 격리된 상태에서 온도, 포커스, 냉각 행, 기존 저장 이관, 수리/무작위 삭제, 시세 및 할인 만료, 환생, 음원 샘플을 검사한다.
